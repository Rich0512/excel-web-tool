# 🏫 台北市延平國小社團課表整理工具 (網頁版)

這是一個專門為了優化「社團與暑假社團錄取名冊」整理流程而開發的純前端行政輔助工具。  
旨在將傳統混亂的多欄位錄取名冊或網頁名冊，自動重組並美化為以「學生」為單位的個人週課表，大幅節省行政同仁手動複製貼上的排版時間。

* 🌐 **免安裝線上版網址**：[https://rich0512.github.io/excel-web-tool/](https://rich0512.github.io/excel-web-tool/)
* 💼 **適用對象**：延平國小社團課務行政人員、導師及相關處室。

---

## 🌟 核心特色

1. **🚀 雙重任務情境：Excel 檔案與網頁複製貼上**
   * **📂 方案一：上傳 Excel 檔案 (適用於：已有錄取名單，純排課表階段)**
     * 支援學校選課系統匯出的**「學期統計報表資訊」**（含「課程與學生清單」與各社團分頁），也能讀取舊版的寒暑假名冊。
     * **一人一列橫向週課表**：同一位學生的多筆選課紀錄（如跨週一至週五）自動彙整為單一行紀錄，不再重複佔列。
     * **社團名稱純淨化**：自動去除開頭的星期前綴（如「周一」、「週二」）與結尾括號（如上課時間），課表僅呈現最純淨社團名稱（如「桌遊社」、「足球社」）。
     * **晨間與多天上課社團**：名稱含「晨間」的社團會排在週五之後的晨間專屬欄位（「晨間(週一、週四)」「晨間(週二、週五)」「晨間(週一、週二、週四、週五)」），依檔案內的上課時間判斷屬於哪一欄，查不到時依名稱推測（例如游泳排在週一、二、四、五）。晨間社團和下午的社團不算衝堂。若要把社團填進每一個上課日，可以在星期選單選「週一、四」「週二、五」「週一、二、四、五」這類多日選項。
     * 上傳後，系統會掃描所有社團及學生，把多個工作表合併重組，產出個人週課表總表（Excel 中的工作表名稱是「課程與學生清單」）。
   * **📋 方案二：貼上網頁複製名單 (適用於：尚未抽籤，需線上抽籤排課階段)**
     * 如果您需要進行**抽籤**，請在此分頁直接貼上從選課系統網頁上「反黑複製」的學生名冊。
     * 每個社團可以設定正取人數、招收年級範圍與抽籤優先順序（高年級優先或低年級優先）。
     * 按「加入這個社團」時就會完成這個社團的**隨機抽籤**，正取、備取立刻列在「已加入的社團」清單。所有社團都加入後，按「下載課表與抽籤結果」，把已抽好的結果匯出成週課表總表（工作表「課程與學生清單」）及各社團的抽籤結果工作表；下載不會重新抽籤。
     * **社團名稱的時段後綴**：社團名稱結尾的時段標示會被辨識並從課表上的名稱清掉，例如「桌遊A」「桌遊（B）」「桌遊-A」「足球第一時段」「舞蹈Slot B」。可辨識的寫法是單獨的 A/B 字母（可加半形或全形括號，全形字母也算），或「第一時段」「一時段」「第一節」「Slot A」等時段字詞。選「寒暑假（有 AB 時段）」模式時，課表會寫成「桌遊(A)」。英文名稱結尾的字母不會被誤判：沒有括號時，A/B 前面若是英文字母就不算時段，所以「Yoga」「LEGO Club」會維持原名；結尾是「A班」時也不算。

 2. **🧠 智慧特徵推斷與即時預覽**
    * 在貼上名冊時，系統會先在前 5 列找欄位標題；沒有選取到標題時，會依內容推測哪一欄是「班級、座號、姓名」。
    * 只讀取班級、座號、姓名三欄，「學號、選課階段、抽籤順序、備註」等其他欄位不會被使用。含「學」字的欄位（例如學號）不會被當成座號；沒有標題時，座號只接受 1 到 60、最多 2 位數的數字，所以較長的學號不會被誤判為座號。
    * **即時解析回饋**：貼上文字後，網頁會顯示讀到幾位學生，以及其中幾位有班級、座號、姓名，方便確認欄位是否解析正確。
    * **社團名稱與星期推測**：貼上的內容開頭若有名單標題（例如含有社團名稱或「週三」的一行），系統會嘗試自動填入「社團名稱」與「上課星期」。自動填入的值可以直接修改；自己選過星期後，貼上新名單也不會再自動改。

 3. **🚨 即時衝突與衝堂警示區 (Live Conflict Detection)**
    * **多社團交叉比對**：在 Excel 模式修改社團名稱或上課星期時，或在貼上模式加入、移除社團，以及切換「時段模式」「包含沒有班級座號的新生」時，系統會在瀏覽器內重新比對所有社團的上課日。貼上模式只比對正取的學生。
    * **即時列表**：若有學生在同一天被兩個以上的社團錄取（衝堂），下方會出現黃色的提醒框，列出班級、座號、姓名及衝突的社團，讓您在下載 Excel 前就能調整。晨間社團與同一天下午的社團不算衝堂。下載的週課表也會在「備註」欄寫出衝堂說明。

 4. **💾 自訂 Excel 檔名與重設機制**
    * 在兩個分頁的下載按鈕上方皆提供「下載的檔名（選填）」輸入框，同仁可自由指派輸出的檔名（例如：115學年度第一學期社團課表），方便建檔與發送。留空時，上傳 Excel 模式沿用原始檔名，貼上名單模式使用「直接貼上名單彙整」；檔名後面會依時段模式加上「_學期社團彙整」或「_寒暑假社團彙整」。
    * 頁首的「清除這次的資料」按鈕會清除選擇的 Excel 檔案、星期設定、已加入的社團，以及瀏覽器記住的社團星期，畫面回到第一步。

 5. **🧠 智慧對照記憶**
    * 上傳 Excel 模式按下「開始轉換並下載課表」時，會用瀏覽器的 `localStorage` 記住這次的「社團 ── 星期」設定，下次在同一個瀏覽器開啟同類名冊時自動預填。只存欄位標題、社團或工作表名稱與星期，不存任何學生資料。
    * 貼上名單模式不會記住任何設定。要刪除記住的設定，按頁首的「清除這次的資料」。

 6. **💅 延平專屬美學排版**
    * **經典延平藍**：產出的 Excel 表頭採用與網頁相同的校徽藍底色搭配白字置中。
    * **自動欄寬調整與斑馬紋**：欄寬依內容長度自動調整，減少出現 `###` 或文字被截斷；週課表總表（工作表「課程與學生清單」）附帶交替斑馬紋方便閱讀。
    * **自動套用篩選器**：週課表總表（工作表「課程與學生清單」）的首行自動附帶 Excel 漏斗篩選器（AutoFilter），方便導師直接篩選各班課表。

 7. **🗳️ 智慧抽籤與年級權重系統 (Lottery Pipeline)**
    * **加入社團時就抽籤**：在「貼上網頁名單」分頁按「加入這個社團」時，系統就會完成這個社團的抽籤，結果立刻列在「已加入的社團」清單（點社團那一列可以展開正取與備取名單）。之後按「下載課表與抽籤結果」只是把清單上已抽好的結果匯出成 Excel，不會再抽一次。下載完成後清單會清空。
    * **抽籤方式**：符合年級限制的學生依年級分組，依照「抽籤優先順序」從第一順位的年級開始，每個年級內部隨機排序後依序填入正取名額；名額滿了以後，其餘學生依抽到的順序成為「備取 1」「備取 2」…。正取的籤序就是抽中的順序（1、2、3…）。
    * **高/低年級優先權**：支援高年級優先（6 → 5 → ... → 1）或低年級優先（1 → 2 → ... → 6），新生（沒有班級）不論選哪一種都排在最後。這是整個年級優先，不是加權機率：前一個年級的學生都排完後，才輪到下一個年級。
    * **年級範圍限制**：限制社團僅能由特定年級報名，超出範圍者不參加抽籤，籤序欄標示「不符限制」。
    * **重複報名只保留一筆**：抽籤前會先去除重複報名。班級、姓名相同，而且座號相同或其中一方沒有座號，就視為同一位學生，只保留第一筆（第一筆沒有座號時補上後面那筆的座號）。同班同名但座號不同時，視為兩位學生。
    * **班級無法辨識**：年級只看班級的第一個有意義的字，例如「301」「3年1班」「三年一班」都是 3 年級；班級空白或寫「新生」視為新生。讀不出 1 到 6 年級的班級（例如「701」「01」「資源班」）不參加抽籤，籤序欄標示「班級無法辨識」，請確認名單後再處理。
    * **提醒只寫筆數**：有重複報名或班級無法辨識時，加入社團後會跳出提醒，只寫筆數，不列出姓名；社團那一列也會標示「略過重複 N 筆」「班級無法辨識 N 筆」與抽籤時間。
    * **安全亂數**：抽籤使用瀏覽器內建的密碼學安全亂數（`crypto.getRandomValues`），並以拒絕取樣（rejection sampling）避免數字小的結果機率偏高。瀏覽器不支援時會跳出提醒且不能抽籤，不會改用一般亂數；請改用最新版 Chrome、Edge 或 Safari。
    * **名單排列順序**：清單與匯出檔的順序是：正取（先依年級，1 到 6 年級、新生最後；同年級再依班級、座號排序）→ 備取（依備取號碼）→ 班級無法辨識 → 不符限制（後兩組依班級、座號排序）。正取的排列只是方便閱讀，不影響已抽好的籤序。
    * **視覺化抽籤結果**：除了產出週課表總表（工作表「課程與學生清單」，只含正取學生）外，還會依社團分別產出抽籤結果工作表，列出所有報名者的班級、座號、姓名與籤序。正取學生的籤序儲存格依年級塗上不同的淺色底，「錄取人數」欄會合併顯示各年級的錄取人數。
    * **抽籤資訊**：每張社團工作表的右側（隔一欄）有「抽籤資訊」表，列出：抽籤時間（年月日時分秒）、抽籤次數、正取人數（含名額）、年級限制、優先順序、報名人數（已去除重複）、重複略過筆數、班級無法辨識筆數、亂數來源。這些都是抽籤設定與筆數，不含學生資料。
    * **重抽紀錄與限制**：要重新抽籤，請在清單上按「移除」（或「全部移除」）後重新加入。按「移除」與「全部移除」時都會先跳出確認視窗，提醒抽籤結果會消失，避免誤按。同名社團再次加入時，系統會先詢問是否確定重新抽籤，確認後才抽籤並把次數記為「第 N 次抽籤」，顯示在清單與「抽籤資訊」中。比對同名社團時只忽略英文大小寫、全形與半形的差別、空白與看不見的字元（例如「LEGO社」與「lego 社」、「ＡＩ社」與「AI社」算同一個社團）；其他改名，例如「桌遊社」改成「桌遊」、加減標點，都會被當成不同的社團，抽籤次數從第 1 次重新算。若沒有移除舊的就再加入，兩份抽籤結果都會匯出，課表也會兩份都算。
      * **請注意**：抽籤次數只記錄「本次開啟網頁後」的次數，存在記憶體中，**重新整理或關閉網頁後會從 0 開始**。因此這個紀錄只能幫忙發現同一次操作中的重抽，不能完全防止重抽。正式抽籤時，建議搭配行政程序把關，例如請其他同仁在場見證、當場下載並保存匯出檔，或把抽籤時間與結果另行簽核。

## 📖 使用步驟說明

### 📂 模式 A：Excel 檔案匯入
1. 在 **「上傳 Excel 檔」** 分頁，將從系統下載的 **「錄取名冊 Excel 檔案」** 拖曳至虛線上傳區，或按 **「選擇檔案」** 手動選取。支援 `.xlsx`、20 MB 以內；舊版 `.xls` 請先用 Excel 另存成 `.xlsx`。還沒有名冊時，可以先點上傳區內的 **「沒有檔案？下載測試用的範本 Excel」** 試用。
2. 系統會自動辨識並列出所有社團：
   * **彙整模式**：有「課程與學生清單」或「總表」工作表時預設為「單一清單」，否則為「多工作表」（每個社團一個工作表），可以手動切換。
   * **修改名稱**：可以直接修改最後輸出在課表上的簡稱（如：將 `週五舞蹈社` 改為 `舞蹈社`）。
   * **設定星期**：為每個社團選擇它在星期幾上課。系統會先依社團名稱中的星期、檔案內的上課時間或上次的設定預填，請逐一確認。
   * 視需要選擇「時段模式」（一般學期／寒暑假），以及是否「包含沒有班級座號的新生名單」。
3. 點擊 **「開始轉換並下載課表」** 即可完成下載。

### 📋 模式 B：直接貼上名單 (網頁複製)
1. 在網頁版點擊上方分頁切換至 **「貼上網頁名單」** 分頁。
2. 將選課網頁上的名冊「完整拖曳反黑選擇 (包含欄位標題)」並複製，貼上到「名單內容」文字框中。
   *(不論您有沒有複製到「選課階段、學號」等欄位，系統只會讀取班級、座號、姓名；名冊內也不需要先有「抽籤順序」欄位)*
3. 確認「社團名稱」與「上課星期」（貼上後可能已自動填入），並依該社團的規定設定「正取人數」、「招收年級」與「抽籤優先順序」。
4. 點擊 **「加入這個社團」**。這時就會抽籤，結果立刻出現在下方「已加入的社團」清單；有重複報名或班級無法辨識時，會跳出只寫筆數的提醒。
5. 如有多個社團需抽籤，請**一次性重複上述步驟加入所有社團**，才能檢查跨社團的衝堂。設定或名單有誤時，按該社團的「移除」並確認後重新加入（會重新抽籤，並記錄抽籤次數）。
6. 確認所有社團皆列在已加入清單後，視需要選擇「時段模式」、是否「包含沒有班級座號的新生」與下載的檔名，再點擊 **「下載課表與抽籤結果」** 匯出已抽好的結果。下載後清單會清空。

## 🛡️ 資安與個資保護說明

本工具在設計上以**個資保護**為優先考量，做法如下：

1. **🔒 只在瀏覽器內處理 (Client-side Processing)**
   * 所有 Excel 解析、隨機抽籤、課表彙整與下載均在您瀏覽器的本機記憶體中完成，**不會上傳至任何外部伺服器或資料庫**。
   * 學生名冊與抽籤結果只存在記憶體中，不會寫入 `localStorage`、`IndexedDB` 等瀏覽器儲存空間。跳出的提醒視窗與錯誤訊息不含學生的姓名、班級、座號，需要指出位置時只寫筆數、工作表名稱或欄位標題（衝堂提醒框是網頁上的列表，會列出學生，方便調整）。
   * 受限於瀏覽器沙箱機制，網頁程式只能讀取您主動選擇的檔案，**無權讀取**電腦硬碟中的其他檔案，也無法修改作業系統設定。

 2. **📦 第三方套件與字型放在網站內 (Self-hosted Assets)**
    * 核心解析庫 `ExcelJS`（4.4.0）放在網站內的 `docs/js/libs/exceljs.min.js`，頁面閒置或需要時才載入，不會拖慢首頁。
    * 網頁字型 `Noto Sans TC` 與 `Outfit` 放在網站內的 `docs/fonts/` 目錄，不向 Google 等外部伺服器請求。（網站本身由 GitHub Pages 提供，開啟網頁時 GitHub 仍會收到一般的連線資訊，例如訪客 IP；名冊內容不會送出。）
    * 不從外部 CDN 載入任何程式或字型，降低第三方供應鏈被劫持（Supply Chain Attack）造成個資外洩的風險；開啟過一次後也可以離線使用（字型例外見下方 PWA 說明）。
    * 已啟用 `Content-Security-Policy` (CSP) 安全策略：程式、樣式、字型與網路連線都只能來自本站（`'self'`，圖片另外允許 `data:`、`blob:`），不開放 `'unsafe-inline'` 與 `'unsafe-eval'`，也禁止表單送出。從瀏覽器層級封鎖向外部伺服器的非預期連線與字串形式的程式碼執行。

 3. **🧹 學生資料只在記憶體 (In-memory Only)**
    * 關閉瀏覽器分頁或重新整理網頁後，記憶體中的學生名冊、抽籤結果與抽籤次數就會消失，不會留在瀏覽器儲存空間裡。
    * 點「整理另一份名冊」或「重新選擇檔案」會清除已讀取的 Excel 名冊；點頁首的「清除這次的資料」會一併清除已加入的社團與瀏覽器記住的社團星期。
    * 瀏覽器記住的「社團 ── 星期」設定（只有社團名稱與星期，見上方「智慧對照記憶」）在關閉分頁後仍會保留，要刪除請按「清除這次的資料」。
    * 下載的課表 Excel 會留在電腦的下載資料夾，含有學生姓名，用完請自行刪除。

## 📱 PWA 離線支援與快速存取

本工具已支援 **Progressive Web App (PWA)** 標準，提供接近原生 App 的使用體驗：

1. **📲 新增至主畫面**
   * 在手機或平板的瀏覽器中開啟本工具後，可點擊「新增至主畫面」（或「安裝應用程式」），即可在桌面建立捷徑圖示，一鍵啟動。
   * 電腦版 Chrome 也可在網址列右側點擊安裝圖示。

2. **✈️ 開啟過一次後可離線使用**
   * 首次開啟網頁後，Service Worker 會自動將執行所需的靜態資源（HTML、CSS、JS、ExcelJS、介面用字型、範本檔案）快取至瀏覽器本機。
   * **之後即使完全斷網**，也能正常開啟並使用所有功能。唯一的差別是中文字型的「其餘常用字檔」只在畫面第一次出現這些字（例如學生姓名）時才下載；若從未在連線時顯示過名單就離線，姓名會改用系統字型顯示，不影響功能與匯出結果。

3. **🔄 自動版本更新**
   * 當開發者更新網頁版本時，Service Worker 會自動偵測變更並更新快取，使用者下次開啟即可使用最新版本。

## 👨‍💻 技術與架構說明
本專案採用**高維護性、模組化架構**進行設計。網站原始檔全部放在 `docs/`（GitHub Pages 的發佈來源），其餘資料夾不會出現在網站上。

**網站（`docs/`）**
* `js/libs/exceljs.min.js`：本地端 Excel 核心處理庫（已下載本地封裝）。
* `js/utils.js`：共用字串分析（星期、年級 `parseGrade`、時段後綴 `splitSlotSuffix`）、安全亂數 `randomInt`、HTML 跳脫與 LocalStorage 存取工具。
* `js/parser.js`：剪貼簿文字智慧分析與特徵識別引擎（含社團名稱與星期推測）。
* `js/processor.js`：學生課表橫向聯結的核心運算、重複報名去重（`dedupeApplicants`）與隨機抽籤演算法（`runClubLottery`）。
* `js/mapping-ui.js`：負責處理多樣模式下的設定表格動態 DOM 生成。
* `js/exporter.js`：Excel 檔案樣式、自動欄寬與斑馬紋樣式包裝，以及社團工作表的「抽籤資訊」表。
* `js/app.js`：主要頁面控制器、按鈕事件綁定與生命週期管理（包括 beforeunload 安全保護）。
* `js/register-sw.js`：註冊 Service Worker。
* `service-worker.js`：PWA 離線快取管理（HTML 採 Network-First，4 秒沒有回應或離線時改用快取；靜態資源採 Cache-First，預快取網址與頁面的 `?v=` 相同）。
* `fonts/`：本地化字型檔（Noto Sans TC + Outfit，僅 WOFF2）。Noto Sans TC 已裁切，每個字重拆成介面用字檔（`-ui`，約 140 KB，首屏只需要它）與其餘常用字檔（`-ext`，約 0.8 MB，畫面出現學生姓名等字時才下載），由 `fonts.css` 的 `unicode-range` 分流；罕用字由系統字型補字。
* `templates/`：測試用的假資料範本。

**開發工具（`tools/`，需要 Node.js）**
* `serve.mjs`：本機預覽，模擬 GitHub Pages 的子路徑與 404（`node tools/serve.mjs` → http://localhost:8000/excel-web-tool/）。
* `check-site.mjs`：部署前檢查（版本號一致、預快取檔案、外部資源、inline 程式碼、CSP 未放寬、404 路徑、試算表外洩、範本只含「測試生」假姓名、manifest 圖示尺寸、介面用字都在字型介面檔內且 `unicode-range` 與字元清單相符）。
* `template-check.mjs`：讀取範本 xlsx 的姓名欄（由 `check-site.mjs` 呼叫）。
* `bump-version.mjs`：同步調升快取版本。
* `test-hooks.mjs`：Claude Code hooks 的回歸測試。
* `test-site.mjs`：網站單元測試入口，依序執行 `tests/*.test.mjs` 並印出總結（`--verbose` 列出每項檢查）。測試用 `node:vm` 載入 `docs/js` 搭配假的 DOM（`tests/harness.mjs`），涵蓋貼上名單的社團與星期推測（含姓名不可推成社團）、社團名稱的時段後綴、抽籤（名額與籤序、年級優先、重複報名、班級無法辨識、安全亂數、重抽計次、抽籤資訊）、Excel 模式的彙整與匯出、上傳與讀取中狀態、對照表、瀏覽器設定上限、ExcelJS 延遲載入、Service Worker 離線備用頁、錯誤訊息不含名冊內容等；資料全部是虛構的。
* `e2e-check.mjs`（選用，需要 Chrome 或 Edge）：以 DevTools Protocol 控制無頭瀏覽器實際操作本機預覽（首頁載入、CSP、上傳與下載、貼上、離線、手機寬度、高延遲）。先執行 `node tools/serve.mjs 8124`，再執行 `node tools/e2e-check.mjs http://localhost:8124/excel-web-tool/ [情境]`；只接受 localhost 網址，瀏覽器設定檔與下載檔放在系統暫存資料夾並於結束時刪除。
* `site-config.mjs`：以上腳本與 hooks 共用的路徑與常數。
* `subset-fonts.py`：重新裁切中文字型並產生 `subset-chars-ui.txt`、`subset-chars-ext.txt` 與 `fonts.css` 的 Noto Sans TC 宣告（需要 Python + fonttools，見 `/subset-fonts`）。

**Claude Code 設定**：`CLAUDE.md` 與 `.claude/`，只在以 `web_demo/` 為工作目錄啟動 Claude Code 時生效。

| 類型 | 名稱 | 用途 |
|---|---|---|
| rules | `privacy`、`memory`（常駐）；`frontend`、`service-worker`、`tooling`（依檔案載入） | 碰到對應檔案時自動載入 |
| skills | `/release`、`/preview`、`/subset-fonts` | 發佈、本機驗證、字型裁切 |
| agents | `pages-auditor`、`frontend-reviewer` | 上線前稽核、前端審查（唯讀，由 `agent-readonly` hook 限制 Bash） |
| hooks | `guard-roster`、`guard-git`（PreToolUse）、`stop-check`（Stop）、`agent-readonly`（子代理專用） | 擋讀取名冊、擋提交名冊、push 前與回覆結束時檢查、子代理只能執行唯讀指令 |
| memory | `~/.claude/projects/excel-web-tool/memory/` | 跨對話記憶（本機，不進 repo） |

### 🚀 發佈流程
1. 修改 `docs/` 後執行 `node tools/bump-version.mjs`，同步調升 Service Worker 快取版本、`index.html` 的 `?v=` 與 `sitemap.xml` 日期（Claude Code 中可執行 `/release`）。
2. 執行 `node tools/check-site.mjs` 確認通過，並用 `node tools/serve.mjs` 在本機實際操作一次。
3. push 到 `main` 後約 1～2 分鐘即上線。
